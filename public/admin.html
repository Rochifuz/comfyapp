🛠️ Admin

Los datos que la app va juntando sola (uso, bugs reportados, ideas de mejora) — no hace falta entrar a la consola de Firebase para verlos. Página sin link en el menú a propósito: se llega escribiendo la URL directo.

🔒 Sin acceso

Tu cuenta no está configurada como admin. Si ya hay algún admin, pedile que te tilde el check "Admin" en la tabla de Usuarios de acá abajo. Para el primer admin (sin nadie que lo habilite todavía): copiá tu UID desde Firebase Console → Authentication → Users y pegalo en firestore.rules, en la función esAdmin() — después hay que volver a desplegar las reglas (npm run deploy o firebase deploy --only firestore:rules).
